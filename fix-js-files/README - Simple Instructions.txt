# ERP Soul Application

## How to Run This Application

### For Non-Technical Users:

1. Make sure you have this entire folder on your computer
2. Double-click the "Run ERP Soul.bat" file
3. Wait for the application to start (this may take a minute the first time)
4. Your browser will automatically open with the application

### What Happens When You Run It:

- The application will open two black windows (don't close these!)
- Your default web browser will open with the application
- You can now use ERP Soul in your browser

### To Close the Application:

1. Close the browser window
2. Close the two black windows by clicking the X in the top-right corner
3. Press any key in the main window when prompted

### Troubleshooting:

- If nothing happens when you double-click "Run ERP Soul.bat":
  - You may need to install Node.js from https://nodejs.org/
  - After installing Node.js, try running "Run ERP Soul.bat" again

- If you see error messages:
  - Make sure you're connected to the internet
  - Try closing all windows and running "Run ERP Soul.bat" again

- If the browser doesn't open automatically:
  - Open your browser and go to http://localhost:5173

## For Advanced Users:

This application consists of:
- A backend server (Node.js)
- A frontend client (React)
- Both run locally on your computer

You can also run individual components:
- "Start Server.bat" - Runs only the backend
- "Start Client.bat" - Runs only the frontend
- "Build App.bat" - Creates a standalone executable
